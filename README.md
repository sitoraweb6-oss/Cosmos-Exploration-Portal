# Cosmos — Space Exploration Portal

An immersive, cinematic sci-fi editorial platform exploring deep space missions, cosmic timelines, and stellar archives — with interactive telemetry logs. Built by [Sitora Web](https://sitora.org).

## About

Cosmos is a storytelling-driven web experience for space enthusiasts: mission archives, cosmic timelines, and stellar data presented with cinematic visuals and fluid interactions — like flipping through a mission-control magazine from the future.

## Features

- Cinematic sci-fi editorial design
- Deep space mission archives and profiles
- Interactive cosmic timelines
- Stellar archives with rich visuals
- Telemetry log interactions
- Fully responsive layout

## Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS 4, Lucide icons
- **Build:** Vite 6
- **Backend:** Express + tsx Node server (bundled via esbuild), Google Gemini AI

## Getting Started

### Prerequisites

- Node.js 18+

### Installation

```bash
npm install
npm run dev
```

The app will be available at `http://localhost:3000`.

### Build for production

```bash
npm run build
npm start
```
